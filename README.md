# 💳 Credit Card UI

Um projeto simples e elegante de **Cartão Bancário Digital**, desenvolvido para praticar conceitos de **HTML5** e **CSS3**, com foco em design moderno e componentes visuais realistas.

---

## 📸 Preview do Projeto

Interface contendo:

- Bandeira do cartão
- Chip bancário
- Número do cartão
- Nome do titular
- Data de validade
- Elementos gráficos decorativos

---

## ✨ Tecnologias Utilizadas

- **HTML5**
- **CSS3**

---

## 🎨 Características do Design

- Visual moderno e sofisticado
- Paleta de cores em preto e dourado
- Efeito de profundidade com sombras
- Bordas arredondadas
- Layout limpo e organizado
- Design inspirado em cartões premium

---

## 🚀 Objetivo do Projeto

Praticar habilidades de desenvolvimento front-end através da criação de um componente visual realista, utilizando técnicas de posicionamento, estilização e responsividade.
